# 📚 libraIf

O **libraIf** é um projeto em Java desenvolvido com foco no aprendizado e prática de **Programação Orientada a Objetos (POO)**.  
A ideia do projeto é simular, de forma gradual, um **sistema de biblioteca**, começando do básico e evoluindo conforme novos conceitos da linguagem Java forem sendo aprendidos.

## Objetivo do Projeto

O principal objetivo do **libraIf** é aprofundar meus conhecimentos na **linguagem Java**, especialmente nos conceitos de **POO**, como:
- Classes e objetos  
- Encapsulamento  
- Métodos e construtores  
- Herança e polimorfismo (futuramente)  
- Boas práticas de organização de código  

Além disso, o projeto foi pensado para ser **evolutivo**, permitindo a adição de novas funcionalidades ao longo do tempo.

## Estado Atual

Atualmente, o projeto encontra-se em **fase inicial de desenvolvimento**, porém já possui funcionalidades básicas implementadas.  
O sistema permite o **cadastro e gerenciamento de livros**, com operações como adição, listagem, busca e remoção, servindo como base para a evolução do projeto.

Novas funcionalidades estão sendo planejadas, como **persistência de dados**, melhorias na organização do código e expansão das regras de negócio.


## Funcionalidades Futuras (planejadas)

Algumas ideias para evoluções futuras do projeto incluem:
- Cadastro e gerenciamento de livros
- Cadastro e gerenciamento de usuários
- Sistema de empréstimo e devolução de livros
- Tratamento de exceções
- Organização em pacotes
- Integração com **banco de dados**
- Outras melhorias conforme o aprendizado em Java avançar

## Tecnologias Utilizadas

- Java
- Programação Orientada a Objetos
- Git e GitHub

## Observação

Este projeto tem fins **educacionais** e será constantemente atualizado conforme novos conhecimentos forem adquiridos.
